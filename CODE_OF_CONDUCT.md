# Code of Conduct

We are committed to maintaining a welcoming, calm, and high-signal technical space for everyone interacting with this repository.

## Expected Behavior
- Keep technical feedback specific, respectful, and backed by primary sources or reproducible evidence.
- Respect differing hardware budgets, operating systems, and experience levels (newcomers and seasoned developers alike).
- Report security concerns privately via [SECURITY.md](SECURITY.md).

## Unacceptable Behavior
- Harassment, personal attacks, trolling, or spam/promotional link dumps.
- Publishing others' private information or credentials without permission.

## Enforcement
Maintainers reserve the right to edit, remove, or close comments, issues, discussions, or pull requests that violate these standards.
